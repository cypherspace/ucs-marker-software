The aim of this project is to build an automated marking software product. 

**Aim for marking software**

The general aim is that a lead teacher of a subject can take paper exam scripts completed by students, assign them to teachers, and the teachers can mark those scripts online. The secondary aim is that the scripts could be marked by AI, and feedback could be generated by AI. 

**Workflow**

Lead teacher scans papers as PDFs and saves them. They go onto the marking system, and set up exam on portal by naming the exam, assigning the subject, year, year group (cohort), exam board, exam series. None required except for name, should be editable later, and some should default (e.g. same teacher is usually responsible for the same subject). 

The lead teacher then assigns teachers to exam. They add a list of students (this could be selected from a group, added manually, or done just by number). Upload papers. Upload mark scheme. Upload examiner reports if possible. 

Paper extraction & clipping: Lead teacher uses admin portal and Python library to draw areas on paper to mark coordinates of individual questions. Those areas are clipped from all papers and saved, alongside original paper. Same happens for MS.

**AI Text Recognition**  
Text recognition functions can be used to generate computerised text instead of handwritten; if OCR libraries exist, use those \- if AI required, use that. 

**AI Marking and AI Feedback**  
Separate function. Can choose number to AI mark vs number to mark by human; or can choose individual papers to AI mark. Set adherence and guidance of the mark scheme; use existing annotations or previous subject examples to guide, or use examiner reports (available from exam boards and can be uploaded alongside exam). Can choose marking, feedback, or both. 

Anonymise papers & number before sending to Gemini \- un-anonymise when results sent back using number. 

Marking sends script/clip to Gemini; receives marked work back according to mark scheme.

Feedback sends script/clip to Gemini (and marking if already done) and receives feedback. 

Comparative marking for more essay-based subjects: Generate comparison/sorting function where pairs of scripts are sent to Gemini and ranked, until a complete rank order is achieved. If a teacher has done marking, made notes and annotations, use those marks and annotations to guide assessment of other scripts.

**Uses & benefits**

Teacher moderation; compare teachers’ marks on the same scripts to agreed marking criteria. 

Anonymised marking \- no names seen (unless written on other pages of script). 

Reduction in bias \- no handwriting bias. 

Mark from anywhere, any time, on assigned papers.
